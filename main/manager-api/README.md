This guide covers development. For deployment, see the [server deployment documentation](../../README.md).

# Project overview

manager-api is built with Spring Boot.

When importing the project into your editor, select the `manager-api` folder as the project directory.

# Development environment
JDK 21
Maven 3.8+
MySQL 8.0+
Redis 5.0+
Vue 3.x

# API documentation
After starting the application, open http://localhost:8002/xiaozhi/doc.html.
