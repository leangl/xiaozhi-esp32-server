## iFlytek streaming TTS

The comments add iFlytek streaming speech-synthesis provider/model, setup notes and voice catalog. Create an application at `https://console.xfyun.cn/app/myapp`, select the service and obtain API configuration at `https://console.xfyun.cn/services/uts`, then purchase the needed service for that APPID, such as ultra-humanlike synthesis. The note describes low-latency bidirectional streaming, colloquial-speech settings and audio controls including volume/rate/pitch. V5 voices do not support the colloquial-speech options.

Voice section comments mean “base characters” and “add the corresponding character voices.” Field labels `oral_level`, `spark_assist`, `stop_split` and `remain` mean colloquial level, enable colloquial speech, server-side sentence splitting and retain written-language style. Preserve source types/defaults even where a label's field type differs from the configured value.
