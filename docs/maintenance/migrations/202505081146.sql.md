## Baidu ASR and Doubao hotwords

The comments add Baidu speech-recognition configuration and provider fields, update Baidu setup notes, update Doubao provider fields and update Doubao ASR setup notes. Baidu: visit `https://console.bce.baidu.com/ai-engine/old/#/ai/speech/app/list`, create an application, obtain AppID/API Key/Secret Key and enter them in the configuration. Check quotas at `https://console.bce.baidu.com/ai-engine/old/#/ai/speech/overview/resource/list`; see `https://ai.baidu.com/ai-doc/SPEECH/0lbxfnc9b` for the language parameter.

Doubao supports Chinese recognition, needs network access and writes output to `tmp/`. Visit `https://console.volcengine.com/speech/app`, create an application, obtain `appid` and `access_token`, then enter them in configuration. The two added form labels mean hotword filename and replacement-word filename. Hotword instructions: `https://www.volcengine.com/docs/6561/155738`.
