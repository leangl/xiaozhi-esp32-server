## Custom TTS requests

The comments change custom TTS request definitions and documentation. Request parameters can support many TTS services. The historical example uses local KokoroTTS: CPU deployment uses `docker run -p 8880:8880 ghcr.io/remsky/kokoro-fastapi-cpu:latest`; GPU deployment uses `docker run --gpus all -p 8880:8880 ghcr.io/remsky/kokoro-fastapi-gpu:latest`. These are quoted historical instructions, not actions performed for translation.

Configure request parameters as JSON in `params`, request headers in `headers`, and the returned audio format. The Kokoro example is `{ "input": "{prompt_text}", "speed": 1, "voice": "zm_yunxi", "stream": true, "download_format": "mp3", "response_format": "mp3", "return_download_link": true }`. Keep `{prompt_text}` unchanged.
