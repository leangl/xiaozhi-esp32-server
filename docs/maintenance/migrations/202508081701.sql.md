## Index-TTS-vLLM streaming TTS

The comments add the provider, model, setup notes and default voice. Index-TTS-vLLM is a vLLM inference service based on Index-TTS, with natural-sounding voices and low-latency streaming for voice interaction. Deploy the service before configuring its API address. Register custom voices in the project's `assets` directory.

Historical steps: clone `https://github.com/Ksuriuri/index-tts-vllm.git`, install dependencies with `pip install -r requirements.txt`, and start with `python app.py`. Default service address: `http://127.0.0.1:11996`. Register other voices in `assets`; supported formats include `pcm`, `wav` and `mp3`. Reference: `https://github.com/Ksuriuri/index-tts-vllm/blob/master/README.md`. The voice section label means “default voice.”
