## SMS registration and telephone regions

The comments add parameters for mobile/SMS registration. Descriptions: `server.name` = system name; `server.beian_icp_num` = ICP registration number, with literal `null` meaning unset; `server.beian_ga_num` = public-security registration number, with `null` meaning unset; `server.enable_mobile_register` = enable phone registration; `server.sms_max_send_count` = maximum SMS messages per phone number per day; `aliyun.sms.access_key_id` / `access_key_secret` = Alibaba Cloud credentials; `sign_name` = SMS signature; `sms_code_template_code` = SMS template. The revised registration note asks whether non-administrators may register.
