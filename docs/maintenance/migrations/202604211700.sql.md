## Shared TTS provider and Doubao ASR 2.0

The comments fix duplicate TTS 2.0 provider codes and add ASR 2.0. The source deletes the separate `SYSTEM_TTS_HSDSTTS_V2` provider as unnecessary, updates the existing streaming-ASR provider by replacing `cluster` with `resource_id`, and updates its model to `volc.bigasr.sauc.duration`. It then adds the Doubao ASR 2.0 model/configuration notes.

Register at `https://www.volcengine.com/`, enable Doubao streaming ASR 2.0 at `https://console.volcengine.com/speech/service/10038` and obtain `appid`/`access_token` at the bottom. Resource variants: duration/hourly `volc.seedasr.sauc.duration` and concurrency `volc.seedasr.sauc.concurrent`. Reference: `https://www.volcengine.com/docs/6561/109979`.

The warning distinguishes ASR 2.0 `volc.seedasr.sauc.duration` from older streaming ASR `volc.bigasr.sauc.duration`. The historical note calls 2.0 cheaper and recommends the concurrent resource for high concurrency; this translation does not verify current prices.
