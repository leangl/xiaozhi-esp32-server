## iFlytek Spark LLM

The model name/code mean “iFlytek Spark cognitive large language model”; the initial description mentions multi-turn dialogue and text generation. The Chinese `api_password` placeholder means “your api_password.” Sign in to `https://www.xfyun.cn/`, create a Spark application and obtain its API Password. Each model has its own password; check the matching password when changing models.

Parameters: `api_password` = application API Password; `model_name` = model name, including `generalv3.5` and `generalv3`; `base_url` defaults to `https://spark-api-open.xf-yun.com/v1`; `temperature` controls randomness in `0–1`, default `0.5`; `max_tokens` defaults to `2048`; `top_p` controls vocabulary diversity through nucleus sampling, default `1.0`; `frequency_penalty` reduces repetition, default `0.0`. Documentation: `https://www.xfyun.cn/doc/spark/HTTP%E8%B0%83%E7%94%A8%E6%96%87%E6%A1%A3.html`.

The initial Chinese `model_code` is a persisted compatibility literal; a later historical migration changes it.
