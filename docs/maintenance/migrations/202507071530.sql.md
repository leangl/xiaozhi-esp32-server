## Alibaba Cloud streaming TTS

The comments add the Alibaba Cloud streaming speech-synthesis provider/model, setup notes and voice catalog. The seed contrasts one-shot synthesis with lower-latency real-time streaming for voice interaction. It supports CosyVoice large-model voices for more natural output and real-time volume/rate/pitch adjustments.

Enable Intelligent Speech Interaction at `https://nls-portal.console.aliyun.com/`, create a project and obtain `appkey` at `/applist`, and get a temporary token at `/overview`. Alternatively configure `access_key_id` and `access_key_secret`; the source recommends this for dynamic token management. Choose Beijing, Shanghai or another regional host to improve latency. `voice` accepts CosyVoice voices such as `longxiaochun` and `longyueyue`. Reference: `https://help.aliyun.com/zh/isi/developer-reference/real-time-speech-synthesis`.

Catalog section comments mean gentle female voices, mature/commanding female voices, male voices, professional announcers, distinctive voices and Cantonese voices. The English catalog table below explains individual voice descriptors.
