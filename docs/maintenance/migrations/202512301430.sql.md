## Paraformer ASR, multilingual Doubao and TTS emotions

### Alibaba Bailian Paraformer

The comments add the Alibaba Bailian Paraformer real-time speech-recognition provider/model and documentation. The initial description advertises multilingual recognition, custom hotwords and semantic sentence segmentation. Sign in at `https://bailian.console.aliyun.com/` and create a key at `https://bailian.console.aliyun.com/#/api-key`. Models: `paraformer-realtime-v2` (historical recommendation), `paraformer-realtime-8k-v2`, `paraformer-realtime-v1`, `paraformer-realtime-8k-v1`. Languages include Chinese/dialects, English, Japanese, Korean, German, French and Russian. Supports `vocabulary_id` custom hotwords, semantic/VAD segmentation, punctuation, ITN and filler-word removal. Hotwords: `https://help.aliyun.com/zh/model-studio/custom-hot-words?`.

`sample_rate` is in Hz: v2 accepts arbitrary rates per the seed, v1 accepts `16000`, and 8k variants accept `8000`. `semantic_punctuation_enabled=false` selects low-latency VAD segmentation; `true` selects more accurate semantic segmentation. `max_sentence_silence` sets a VAD silence threshold in `200–6000ms`. Reference: `https://help.aliyun.com/zh/model-studio/websocket-for-paraformer-real-time-service`.

### Doubao multilingual recognition

The comments update streaming ASR fields/defaults. The remark repeats the historical distinction between per-request ordinary ASR and time-based streaming ASR, calling the former cheaper in general and the latter better through large-model technology. Create an application at `https://console.volcengine.com/speech/app`, obtain `appid`/`access_token`, and enter them in configuration. Supports Chinese; requires network access; output goes in `tmp/`. Hotwords: `https://www.volcengine.com/docs/6561/155738`.

If multilingual mode is on, set `language`; the note says an empty value supports Chinese/English, Shanghainese, Southern Min, Sichuan, Shaanxi and Cantonese recognition. Other languages: `https://www.volcengine.com/docs/6561/1354869`. The SQL adds `enable_multilingual=false` and `language=zh-CN` only if both keys are absent.

### Volcengine multi-emotion voices

The comments add multi-emotion parameters and defaults. Setup: register at `https://www.volcengine.com/`, enable large-model synthesis and purchase voices at `https://console.volcengine.com/speech/service/10007`, obtain `appid`/`access_token` at the bottom, and use resource `volc.service_type.10029` for synthesis/mixing. Connection reuse defaults to true; idle listening connections consume concurrency slots. Optional rate/volume: `-50–100`, normal default `0`; pitch: `-12–12`, default `0`. Only some voices support emotions; see `https://www.volcengine.com/docs/6561/1257544`. `emotion_scale` ranges `1–5`, default `4`; `emotion` accepts `neutral`, `happy`, `sad`, `angry`, `fearful`, `disgusted`, `surprised`. The SQL adds emotion defaults only when both keys are absent.
