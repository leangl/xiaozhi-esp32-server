## iFlytek streaming ASR

The comments add iFlytek streaming speech recognition and update its documentation. The names/initial remark describe streaming speech recognition for Mandarin and multiple dialects. Sign in to `https://www.xfyun.cn/`, create a recognition application and obtain APPID/APISecret/APIKey.

`app_id` is the application ID; `api_key` authenticates API access; `api_secret` generates signatures; `domain` is the recognition domain, default `slm` (intelligent speech transcription); `language` defaults to `zh_cn` (Chinese); `accent` defaults to `mandarin` (Mandarin) and supports values such as `cantonese`; `dwa` defaults to `wpgs` (dynamic correction on); `output_dir` defaults to `tmp/`. Supports real-time streaming voice interaction and multiple languages/dialects. Reference: `https://www.xfyun.cn/doc/spark/spark_zh_iat.html`.

Compatibility exception: the initial Chinese `model_code` in line 7 means “iFlytek streaming speech recognition.” It is persisted data; a later historical migration changes it. Do not rename it here.
