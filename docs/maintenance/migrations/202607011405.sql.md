## FunASR recognition language

The English comments add a language option to local FunASR and update its description. The Chinese setup note says to download models into `xiaozhi-server/models/SenseVoiceSmall`; supports Chinese, Japanese, Korean and Cantonese recognition; local inference needs no network access; audio awaiting recognition goes in `tmp/`. The recognition-language field controls the language: `auto` detects it; `zh` restricts to Chinese; `en` = English, `ja` = Japanese, `ko` = Korean, `yue` = Cantonese. The source adds `language=auto` only if absent.
