## Volcengine WebSocket reuse

The comment adds the connection-reuse option. Setup repeats account registration at `https://www.volcengine.com/`, speech-model/voice purchase at `https://console.volcengine.com/speech/service/10007`, credentials at the page bottom and fixed `volc.service_type.10029` for synthesis/mixing. Enter the values in configuration.

`enable_ws_reuse` defaults to `true` to reduce connection overhead. Warning: while the device listens, an idle reused connection still consumes a concurrency slot. Optional speaking rate and volume range `-50–100`, normal default `0`; pitch ranges `-12–12`, default `0`.
