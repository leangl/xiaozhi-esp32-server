## RAGFlow provider and setup

The comments add the RAG provider and model configuration. The Chinese placeholder means “your RAG key.” The historical setup description gives these commands in order:

```text
sysctl vm.max_map_count
sysctl -w vm.max_map_count=262144
git clone https://github.com/infiniflow/ragflow.git
docker compose -f docker-compose.yml up -d
docker logs -f docker-ragflow-cpu-1
```

After deployment, register/sign in and click the upper-right avatar to obtain the RAGFlow API key and API server URL. Before use, add models in Model Provider and choose a default model.

To disable registration, the historical note says to stop the service with `docker compose down`, replace `REGISTER_ENABLED=1` with `REGISTER_ENABLED=0` in `.env` using its quoted `sed -i ''s/REGISTER_ENABLED=1/REGISTER_ENABLED=0/g'' .env` command, inspect it with `cat .env | grep -i register`, and restart after confirming `REGISTER_ENABLED=0`. Preserve the historical shell quoting as data; do not execute these instructions for translation. Reference: `https://github.com/infiniflow/ragflow/blob/main/README_zh.md`.
