## Volcengine TTS audio controls

The comment adds speaking-rate, pitch and related provider controls. Setup: register at `https://www.volcengine.com/`, enable large-model speech synthesis and purchase voices at `https://console.volcengine.com/speech/service/10007`, obtain `appid`/`access_token` at the page bottom and enter them in configuration. Use `volc.service_type.10029` for large-model synthesis/mixing. Optional `speech_rate` and `loudness_rate` range from `-50` to `100`, with normal default `0`. Optional `pitch` ranges from `-12` to `12`, default `0`. The source skips step 4.
