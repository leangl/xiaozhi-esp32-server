## PaddleSpeech streaming TTS

The comments add the provider/model, setup documentation and default voice after deleting old voices. PaddleSpeech is Baidu PaddlePaddle's open-source speech-synthesis tool, supporting local offline deployment and model training; framework: `https://www.paddlepaddle.org.cn/`. Supports WebSocket and HTTP; the default uses WebSocket streaming. Deploy the local service before use; default address: `ws://127.0.0.1:8092/paddlespeech/tts/streaming`. Supports custom speaker, rate, volume and sample rate. References: `https://github.com/PaddlePaddle/PaddleSpeech` and `https://github.com/xinnan-tech/xiaozhi-esp32-server/blob/main/docs/paddlespeech-deploy.md`.
