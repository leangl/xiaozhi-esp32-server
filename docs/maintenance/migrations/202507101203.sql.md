## OpenAI-compatible ASR

The comments add an OpenAI ASR provider/model and a Groq ASR model, then update both setup descriptions. Their names mean “OpenAI/Groq speech recognition.”

OpenAI: create an organization and obtain `api_key`. Supports Chinese, English, Japanese, Korean and other languages; see `https://platform.openai.com/docs/guides/speech-to-text`. Needs network access; output goes in `tmp/`. Sign in at `https://auth.openai.com/log-in`, create a key at `https://platform.openai.com/settings/organization/api-keys`, then choose `gpt-4o-transcribe` or GPT-4o mini Transcribe. API reference: `https://platform.openai.com/docs/api-reference/audio/createTranscription`.

Groq: sign in at `https://console.groq.com/home`, create a key at `https://console.groq.com/keys` and choose `whisper-large-v3-turbo` or `whisper-large-v3`; `distil-whisper-large-v3-en` supports English transcription only. Reference: `https://console.groq.com/docs/speech-to-text`. These are historical seed instructions, not current model recommendations.
