## Volcengine bidirectional streaming TTS JSON groups

The comments consolidate separate `speech_rate`, `loudness_rate`, `pitch`, `emotion` and `emotion_scale` controls into three JSON dictionaries: `audio_params` (audio output), `additions` (advanced text processing) and `mix_speaker` (voice mixing). The next comments migrate existing settings, delete the old separate keys, and update links/notes. The SQL copies rate/volume/pitch with integer casts and default `0`; it does not copy the old emotion fields before removing them. This describes historical behavior without repairing it.

Setup note: register at `https://www.volcengine.com/`, enable large-model synthesis and purchase voices at `https://console.volcengine.com/speech/service/10007`, obtain `appid`/`access_token` at the page bottom and use fixed resource `volc.service_type.10029`. Connection reuse defaults to true to reduce overhead; idle listening connections consume concurrency slots.

Parameter documentation: `https://www.volcengine.com/docs/6561/1329505`. You may add audio/advanced parameters supported by the provider:

- `audio_params.speech_rate`: `-50–100`, default `0`; `loudness_rate`: `-50–100`, default `0`; `emotion`: `neutral`, `happy`, `sad`, `angry`, `fearful`, `disgusted`, `surprised`, for supported voices only; `emotion_scale`: `1–5`, default `4`. Example: `{"speech_rate": 10, "loudness_rate": 5, "emotion": "happy", "emotion_scale": 4}`.
- `additions.post_process.pitch`: `-12–12`, default `0`; `aigc_metadata`: AIGC metadata settings; `cache_config`: cache settings. Example: `{"post_process": {"pitch": 2}, "aigc_metadata": {}, "cache_config": {}}`.
- `mix_speaker`: multiple-voice mixing, mainly for Doubao TTS 1.0 voices. Example: `{"speakers": [{"source_speaker": "zh_male_bvlazysheep","mix_factor": 0.3}, {"source_speaker": "BV120_streaming","mix_factor": 0.3}, {"source_speaker": "zh_male_ahu_conversation_wvae_bigtts","mix_factor": 0.4}]}`.

The warning reiterates that emotion fields work only for some voices; list: `https://www.volcengine.com/docs/6561/1257544`. Add further fields according to provider documentation. For mixing, set `req_params.speaker=custom_mix_bigtts`.
