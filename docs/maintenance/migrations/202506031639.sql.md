## Doubao streaming speech recognition

The first two copied section comments say “VLLM provider/configuration,” but the rows add the Doubao streaming ASR provider/configuration. Display names mean “Volcengine/Doubao speech recognition (streaming).” Both updated ASR remarks say: ordinary Doubao ASR charges per request, while streaming ASR charges by time; the historical note calls per-request service cheaper in general but claims better results from the streaming large model. Create an application at `https://console.volcengine.com/speech/app`, obtain `appid` and `access_token` and enter them in configuration. Supports Chinese recognition, requires network access and stores output in `tmp/`. For hotwords see `https://www.volcengine.com/docs/6561/155738`. These are historical billing descriptions, not current price comparisons.
