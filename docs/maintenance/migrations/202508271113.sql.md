## VOSK offline ASR

The comments add the VOSK offline speech-recognition provider/model and setup documentation. VOSK supports multiple languages offline. Download models from `https://alphacephei.com/vosk/models`; the seed recommends `vosk-model-small-cn-0.22` or `vosk-model-cn-0.22` for Chinese. Extract into `models/vosk/` under the project and configure the correct model path. Recognition needs no network connection; output goes in `tmp/`. Chinese model output has spaces between words and no punctuation. Project: `https://alphacephei.com/vosk/`.
