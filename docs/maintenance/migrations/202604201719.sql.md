## Doubao speech synthesis 2.0

The comments add the Doubao speech-synthesis 2.0 provider/model using `seed-tts-2.0`. It shares the bidirectional-streaming configuration layout but uses this resource ID rather than `volc.service_type.10029`. Other comments insert the provider/configuration, add documentation and seed voices described as matching the earlier streaming TTS catalog.

Register at `https://www.volcengine.com/`, enable large-model speech synthesis and purchase voices at `https://console.volcengine.com/speech/service/10035`, obtain `appid`/`access_token` at the page bottom and use `seed-tts-2.0`. Connection reuse defaults to true; idle listening connections still consume concurrency slots. Parameter reference: `https://www.volcengine.com/docs/6561/1329505`.

`audio_params` means audio output settings and accepts supported provider parameters. `speech_rate`/`loudness_rate` range `-50–100`, default `0`; example: `{"speech_rate": 10, "loudness_rate": 5}`. `additions` means advanced text-processing settings: `post_process.pitch` ranges `-12–12`, default `0`; `aigc_metadata` configures AIGC metadata; `cache_config` configures caching. Example: `{"post_process": {"pitch": 2}, "aigc_metadata": {}, "cache_config": {}}`.

The warning repeats the resource-ID distinction and says users may add more supported API parameters. Voice reference: `https://www.volcengine.com/docs/6561/1257544`.
