## Alibaba Cloud streaming ASR

The comments add the Alibaba Cloud streaming speech-recognition provider/model and its setup notes. The seed distinguishes one-shot ASR from real-time streaming recognition, describing lower latency and better real-time interaction. It supports Chinese recognition, punctuation prediction and inverse text normalization. Network access is required; output goes in `tmp/`.

Enable Intelligent Speech Interaction at `https://nls-portal.console.aliyun.com/`, create a project and obtain `appkey` at `/applist`, and get a temporary token at `/overview`. Alternatively configure `access_key_id` and `access_key_secret` to obtain tokens; the source recommends this for dynamic token management. `max_sentence_silence` controls sentence-end detection in milliseconds, default `800`. Reference: `https://help.aliyun.com/zh/isi/developer-reference/real-time-speech-recognition`.
