## PowerMem memory provider

The comments add the PowerMem memory provider/configuration and its setup notes. The display name means “PowerMem memory.” Chinese credential placeholders mean “your LLM API key” and “your embedding-model API key.” Field annotations below explain all form labels.

PowerMem is OceanBase's open-source agent-memory component; the note says it summarizes memory through a local LLM. Project: `https://github.com/oceanbase/powermem`; website: `https://www.powermem.ai/`; examples: `https://github.com/oceanbase/powermem/tree/main/examples`.

### Costs and user profiles

The historical note calls PowerMem free and says costs depend on the chosen LLM/database: SQLite plus a free LLM such as `glm-4-flash` is described as free, while cloud LLM/database services charge their own fees. These are historical claims, not current pricing guarantees.

`enable_user_profile=false` uses ordinary `AsyncMemory`; `true` uses `UserMemory` to extract user information. The note lists `oceanbase`, `seekdb` and `sqlite` as profile-capable stores in PowerMem `0.3.0+`.

### LLM and embedder

The LLM summarizes memory and extracts profiles. Provider choices: `qwen` (Qwen; API key at `https://bailian.console.aliyun.com/?apiKey=1#/api-key`), `openai` (OpenAI-compatible API) and `zhipu` (Zhipu AI; key at `https://bigmodel.cn/usercenter/proj-mgmt/apikeys`; the note recommends the historically free `glm-4-flash`). In the described `config`, `api_key` is required; `model` can be `qwen-plus` or `glm-4-flash`; `openai_base_url` is an optional custom service URL such as `https://api.openai.com/v1`. Examples: `{"provider": "zhipu", "config": {"api_key": "your_key", "model": "glm-4-flash"}}` and `{"provider": "qwen", "config": {"api_key": "your_key", "model": "qwen-plus"}}`.

The embedder converts memory to vectors. Providers: `qwen` and `openai` (OpenAI-compatible). `api_key` is required; `model` can be `text-embedding-v4` or `text-embedding-3-small`; `openai_base_url` is optional; set `embedding_dims` for dimensions other than `1536`. Example: `{"provider": "openai", "config": {"api_key": "your_key", "model": "text-embedding-v4", "openai_base_url": "https://dashscope.aliyuncs.com/compatible-mode/v1"}}`. Preserve the distinction between flat seed fields and these nested explanatory examples.

### Vector storage

The vector store saves embedded memory. The note lists SQLite (lightweight local store, recommended for beginners, no extra configuration), OceanBase (recommended for production/performance), SeekDB (recommended integrated AI/application storage) and PostgreSQL. SQLite example: `{"provider": "sqlite", "config": {}}`.

OceanBase example:

```text
{"provider": "oceanbase", "config": {
  "host": "127.0.0.1",
  "port": 2881,
  "user": "root@test",
  "password": "your_password",
  "db_name": "powermem",
  "collection_name": "memories",
  "embedding_model_dims": 1024
}}
```

`collection_name` is the default table name; the historical note suggests deleting the table or changing its name after a dimension mismatch. This companion does not authorize either operation. Match `embedding_model_dims` to the embedder; the source examples give Zhipu `embedding-2=1024` and `embedding-3=2048`.

The historical “free” combination is Zhipu `glm-4-flash`, Qwen `text-embedding-v4` and SQLite; it does not establish that the embedding service is free. Its production combination is `qwen-plus` or another commercial model, `text-embedding-v4` and OceanBase/SeekDB. This task invokes none of these services.
