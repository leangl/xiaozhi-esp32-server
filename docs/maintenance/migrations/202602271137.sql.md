## Tencent and Coze TTS controls

The comments add Tencent format/rate/volume controls, update defaults and document them, then add Coze China rate/volume-gain controls and notes.

Tencent: enable speech services, use voice `101001` or another supported voice, provide network access and write output to `tmp/`. Obtain keys at `https://console.cloud.tencent.com/cam/capi`, claim historical resources at `https://console.cloud.tencent.com/tts/resourcebundle`, create an application, obtain `appid`/`secret_id`/`secret_key`, then enter them in configuration. `format` accepts `pcm`, `wav`, `mp3`; `speed` ranges `-2–6`, default `0`; `volume` ranges `-10–10`, default `0`.

Coze: register/sign in at `https://www.coze.cn/`, create an application, get `access_token` and choose a voice ID. `response_format` accepts `pcm`, `wav`, `mp3`; `speed` ranges `0.5–2`, default `1`; `loudness_rate` is volume gain in `-50–100`, default `0`.
