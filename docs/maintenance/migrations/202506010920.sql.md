## Vision model configuration

The comments add the OpenAI-compatible VLLM provider, a Zhipu vision AI configuration, setup documentation, HTTP parameters and vision-model fields on agents/templates. The provider name means “OpenAI interface”; the model name means “Zhipu vision AI.” The API-key placeholder means “your API key.” Register and obtain a key at `https://bigmodel.cn/usercenter/proj-mgmt/apikeys`, then enter it in configuration.

`server.http_port` is the HTTP port for the vision-analysis API. `server.vision_explain` contains vision-analysis API addresses sent to devices, separated by `;`. `vllm_model_id` means vision model ID.
